# 欢迎使用 KairosMd ヾ(≧▽≦*)o

> 二次元极简 Markdown 阅读器，主题换装、粒子特效、插件扩展，一应俱全。

KairosMd 是一款用 Go + Wails + Vue 3 打造的桌面 Markdown **阅读器**。它把"读文档"这件事做得轻盈又好看——圆角卡片、毛玻璃侧栏、樱花飘落，还能一键切换四种主题。

## ✨ 核心特性

- **极简阅读**：打开即读，沉浸模式（F11），阅读位置记忆
- **二次元换装**：樱 / 宙 / 枫 / 墨 四款内置主题，热切换不重载
- **高扩展性**：主题包 + 插件系统（Obsidian 式简化 API）
- **排版自由**：字号、行距、页宽、字体实时调节
- **代码高亮**：Shiki，内置常用语言，未加载语言自动按需补载
- **数学公式**：KaTeX
- **轻量**：安装包约 14 MB，启动飞快

## ⌨️ 常用快捷键

| 快捷键 | 功能 |
|---|---|
| `Ctrl` + `O` | 打开文件 |
| `Ctrl` + `K` | 命令面板 |
| `Ctrl` + `,` | 设置 |
| `F11` | 沉浸阅读模式 |
| `Alt` + `T` | 切换主题 |
| `Ctrl` + `=` / `-` | 增大 / 减小字号 |
| `Ctrl` + `R` | 重新加载当前文档 |
