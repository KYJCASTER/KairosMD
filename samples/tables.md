# 表格与任务列表

## 表格

| 功能 | 快捷键 | 说明 |
|---|---|---|
| 打开文件 | `Ctrl + O` | 选择单个 Markdown 文件 |
| 打开文件夹 | `Ctrl + Shift + O` | 建立文件树并监听变化 |
| 命令面板 | `Ctrl + K` | 搜索并执行命令 |
| 沉浸模式 | `F11` | 隐藏全部面板专注阅读 |

对齐方式：

| 左对齐 | 居中对齐 | 右对齐 |
| :--- | :---: | ---: |
| 左 | 中 | 右 |
| AAAA | BBBB | CCCC |
